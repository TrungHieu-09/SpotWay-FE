# UI Design System

Khi xây dựng UI Indoor Spatial, đọc và tuân thủ `docs/DESIGN_SYSTEM.md`. Dùng `appTheme` từ `src/theme/theme.ts`, các token CSS trong `src/styles/global.css` và component chung trong `src/components/ui/`. Không thêm mã màu rải rác trong page/component, không dùng emoji, giữ nội dung tiếng Việt và hỗ trợ responsive dưới 900px.
